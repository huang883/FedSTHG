# 需要作者/数据提供方确认的事项

以下事项不能通过“测试通过”自动解决，也没有代用户联系作者。

1. 作者代码、预训练模型和补充表S1；所提供稿件与正式发表版本是否一致。
2. 精确受试者ID列表、QC排除规则，特别是UCLA99与公开元数据109条的对应关系。
3. 原始影像预处理工具版本、slice timing/TR、丢弃帧数、头动剔除、滤波频段、GSR/混杂回归顺序、AAL文件和列顺序。
4. 锚点平均范围/边界处理、短序列如何扩展到116、窗口长度与步长。
5. 时间输入投影所有层和维度、位置编码长度与初始化；为何表6参数量1.914M与正文直接实现约0.630M不同。
6. 受试者k_p、本地adapter与分类头的每层结构、bias/激活/归一化/dropout设置。
7. 五个随机种子的具体值、折划分文件、验证划分、测试批次顺序；是否按类别分层。
8. AdamW的beta/epsilon、优化器动量是否跨阶段/轮次持久；参数衰减是否排除LayerNorm/bias。
9. 跨客户端指标是macro还是pooled；AUC是否先按站点计算；标准差ddof。
10. 消融的维度调整、去个性化的聚合参数、简单融合具体定义。
11. 超边消息强度的具体标量化方法、ROI遮挡值、25个模型的检查点与代表集合选取规则。

REST-meta-MDD需要用户/所属机构签署DUA并申请密码；私有ID数据需要明确授权。未经授权不下载受限数据、不发送申请邮件。其他尚可独立完成的开发与公开数据实验继续进行。
