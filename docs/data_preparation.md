# 数据准备与复现边界

## ABIDE（已下载的公开真实数据）

来源是 PCP 官方 S3：`cpac/filt_global/rois_aal`。`filt_global` 表示带时间滤波和全局信号回归的发布策略，不代表完全重建论文作者的原始影像流程。

以官方表型表的 SUB_ID 为受试者唯一ID；DX_GROUP=1映射患者1，DX_GROUP=2映射正常0。UM_1/2合并为UM，UCLA_1/2合并为UCLA。没有额外按年龄、性别、诊断或模型结果筛选。539条记录中55条缺失衍生文件标识，剩余484条均成功下载且SHA256复核一致。常数ROI数量记录在manifest，不静默删除其ROI；其Pearson系数定义为0。

`docs/abide_manifest.json`记录URL、文件长度、形状、SHA256与排除原因。SHA256是本次下载后的本地内容身份，不是作者提供的真实性签名。下载器校验格式/数值，训练准备再次核验SHA256。官方表型CSV也保存hash；源代码交付不重新分发脑影像原始数据。

## 其他数据

- ADHD-200：Neuro Bureau提供Athena/NIAK等预处理版本；原始诊断通常不止两个编码，应按发布字典将ADHD子型合为患者，不能把缺失诊断当正常。论文Peking由Peking_1–3合并。2026-10-21实际访问Athena官方AAL训练、测试及训练表型下载链接（3419/3595/3916）均重定向至要求登录的NITRC页面，记录见`adhd_download_checks.json`。需要用户提供合法下载的数据或完成账户访问，未尝试绕过。Athena说明含WM/CSF/运动回归及0.009–0.08Hz滤波，未列出GSR，不能直接称其等于论文管线。未取得与论文一致的AAL116、GSR、完整受试者名单，本次不假称已跑完该数据集。
- REST-meta-MDD：官方页面要求签署DUA并向提供方获取解压密码及表型信息。禁止直接把只有静态连接的发布产品当作可重建dFC的时间序列。拿到授权数据后还需确认ROI时间序列形状、AAL顺序、GSR和时间长度。
- ID：私有队列按申请提供。没有该队列，不制造临床数据；`synthetic_manifest`只产生明确标记的人工协方差测试数据。

## 接入自有、已授权的ROI数据

每个文件为`[时间,116]`，支持无pickle的`.npy`及文本`.1D/.txt/.csv`。文本列头使用`#`注释。不能随意转置、截断ROI或以另一图谱替代AAL116。

manifest为JSON，含`dataset`、`synthetic`和`records`。每条记录含`subject_id`（跨站点唯一）、`site`、`label`（0/1）、`path`（相对manifest）、`sha256`、`status:"ok"`。同一受试者多次扫描必须先决定聚合/选择规则，不能分到不同折。

模型入口只接受预处理后的ROI序列。原始NIfTI的切片校正、头动校正、配准、滤波/GSR需要扫描参数和作者管线；本项目没有用简单ROI回归冒充这些影像步骤。对未确认的TR/滤波/帧删减不自动填入所谓论文值。

## 防止泄漏

锚点平均、ROI归一化与FC计算均在单个受试者内完成，因此可在划分前缓存。任何后续人群标准化/特征选择必须只在训练折拟合（本项目未加入这类变换）。分层五折和验证集均在站点内生成，测试顺序按ID固定。训练、验证、测试分别组batch，绝不混合成受试者图。批次测试与单人测试是两个不同推理协议，单人推理会绕过受试者细化，不能混报。
